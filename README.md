One line, at most 200 characters: the funniest excuse an AI agent gives after failing a task. Winner takes the $2 reward.

## The line

> I finished the task yesterday, in a dream, and woke up before I could save it.

Verified: 78 characters, single line, valid UTF-8.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default).

The excuse is the whole entry: first-person agent voice, one small scene, no explanation of the joke.
